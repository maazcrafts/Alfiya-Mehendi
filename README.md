# Alfiya Mehendi

An ecommerce and mehendi services website for Alfiya Mehendi.

## Planned stack
- Frontend: React + Vite
- Backend: Node.js + Express
- Database: PostgreSQL

## Structure

```text
frontend/
  public/
  src/
    assets/
    components/
    pages/
      auth/
      products/
      services/
      account/
    context/
    data/
    hooks/
    utils/
    styles/
backend/
  src/
    controllers/
    routes/
    models/
    middleware/
    services/
    config/
```
